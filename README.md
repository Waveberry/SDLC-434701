# Cheq — учебная документация

**Автор:** Голуб А. В., группа 434701  
**Дисциплина:** Жизненный цикл разработки программного обеспечения

Cheq — Android-приложение для личного учёта чеков, товаров и расходов. В этой ветке находится документация лабораторной № 3 по исходникам версии 0.9.0: [спецификация требований](srs/srs-cheq.md), [модели SysML v2](srs/models/README.md), [13 представлений SysML](srs/images/sysml), [план верификации](srs/verification.md), [вопросы заказчику](srs/review.md) и [отчёт](srs/lab3.docx).

Локальный OCR читает текст фото; Groq автоматически выделяет товары. Без сети импорт остаётся в сохраняемой очереди. Ручной ввод, архив и расчёты с кешированными курсами работают автономно. НБРБ предоставляет исторические курсы. Чеки учитываются в расходах после проверки и сохранения пользователем.
