- **Автор:** Голуб А. В., группа 434701

Настольное приложение на Java Swing переводит заданную массу между восемью единицами измерения. Ввод выполняется в отдельном окне; после успешного расчёта последнее введённое значение сохраняется до закрытия программы. Предметные единицы используют условные коэффициенты, приведённые в отчёте.

## Сборка и запуск

Требуется JDK 17 или новее. В Windows запустите `.vscode/build.cmd` либо выполните в терминале:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .vscode/build.ps1
java -jar build/WeightConverter.jar
```

Скрипт компилирует `src/lab/*.java` с параметром `--release 17` и создаёт JAR в каталоге `build/`. Этот каталог исключён из Git.

## Состав проекта

- `src/lab/` — модель, представление, контроллер и точка входа приложения;
- `.vscode/` — настройки редактора, запуска и сборки;
- `lab1.docx` — отчёт по лабораторной работе №1.
