**Учебный проект:** конвертер единиц веса

## О проекте

Проект предназначен для проектирования и разработки настольного приложения, которое принимает массу, исходную и конечную единицы измерения и показывает результат пересчёта. Заготовка в этой ветке пока не содержит реализации: исходный код и материалы лабораторной работы №1 находятся в отдельной ветке `lab1`.

## Структура

- `project/src/` — будущие исходные файлы приложения;
- `project/tests/` — будущие проверки;
- `project/docs/` — документация проекта;
- `srs/`, `sdd/`, `adr/` — учебные шаблоны требований, проектирования и архитектурных решений из [исходного репозитория](https://github.com/BSUIR-SDLC/SDLC).

Каталоги заготовки содержат только файлы `.gitkeep`, чтобы пустая структура сохранялась в Git.
